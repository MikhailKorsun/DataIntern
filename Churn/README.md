# Прогнозирование оттока клиентов банка (Churn Prediction) 🏦

## Описание проекта
Данный проект посвящен анализу причин ухода клиентов из банка и построению предсказательной модели. Цель работы — выявить ключевые факторы лояльности и обучить алгоритм, который сможет заранее определять клиентов, склонных к закрытию счета.

## Стек технологий
* **Язык:** Python 🐍
* **Библиотеки:**
    * `Pandas` — обработка и анализ данных.
    * `Matplotlib`, `Seaborn` — визуализация зависимостей.
    * `Scikit-learn` — построение модели машинного обучения и оценка метрик.

## Основные этапы работы

### 1. Исследовательский анализ данных (EDA)
В ходе анализа были выявлены следующие закономерности:
* **География:** В Германии доля оттока составляет **32.4%**, что в два раза выше, чем во Франции и Испании (~16%).
* **Возраст:** Наиболее рискованная группа — клиенты в возрасте **40-55 лет**.
* **Баланс:** Клиенты с более высокими остатками на счетах уходят чаще, что требует внимания к премиальному сегменту.

### 2. Подготовка данных
* Удалены неинформативные признаки (`RowNumber`, `CustomerId`, `Surname`).
* Выполнено кодирование категориальных признаков (`Geography`, `Gender`) с помощью метода One-Hot Encoding.
* Данные разделены на обучающую (80%) и тестовую (20%) выборки.

### 3. Обучение модели
Для решения задачи классификации был выбран алгоритм **Random Forest (Случайный лес)**.
* Количество деревьев: 100.
* Фиксация случайности (`random_state=42`) для воспроизводимости результатов.

## Результаты и метрики
Модель показала следующие результаты на тестовых данных:
* **Accuracy (Общая точность): 86.65%**
* **Precision (Точность для оттока): 0.76** — в 76% случаев предсказание ухода оказывается верным.
* **Recall (Полнота для оттока): 0.47** — модель находит почти половину клиентов, планирующих уход.

**Самые важные признаки для модели (Feature Importance):**
1. Возраст (`Age`) — ключевой фактор.
2. Предполагаемая зарплата (`EstimatedSalary`).
3. Кредитный рейтинг (`CreditScore`).

## Бизнес-рекомендации
* **Удержание клиентов 40+:** Разработать целевые предложения для зрелой аудитории.
* **Аудит в Германии:** Провести исследование качества сервиса или конкурентной среды в немецких филиалах.
* **Стимулирование активности:** Активные клиенты уходят реже, поэтому важно развивать программы лояльности и вовлеченности.

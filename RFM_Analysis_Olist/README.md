# Анализ поведения клиентов e-commerce и RFM-сегментация

## Описание проекта
Данный проект посвящен исследованию клиентской базы бразильского маркетплейса Olist. Цель работы — провести сегментацию пользователей по методологии RFM (Recency, Frequency, Monetary), выявить наиболее ценные группы клиентов и определить факторы, влияющие на повторные покупки.

## Стек технологий
* Язык: Python
* Библиотеки:
    * Pandas, NumPy — обработка и трансформация данных.
    * Matplotlib, Seaborn — визуализация распределений и выбросов.
    * Squarify — построение древовидных карт (Treemaps) для сегментации.

## Основные этапы работы

### 1. Подготовка и очистка данных
Для корректности анализа был выполнен комплексный этап предобработки:
* Интеграция данных: Объединение таблиц заказов, клиентов и товаров.
* Фильтрация: В анализ включены только завершенные заказы со статусом delivered.
* Работа с датами: Столбцы с временем приведены к формату datetime64 для расчета метрики Recency.

### 2. Исследовательский анализ данных (EDA)
В ходе анализа были выявлены ключевые характеристики бизнеса:
* Динамика: В 2017 году наблюдался рост заказов, пик активности зафиксирован в период распродаж.
* Цены: С помощью Boxplot выявлено, что 50% товаров стоят в диапазоне 40-150 ед. Обнаружены ценовые аномалии (товары > 300 ед.), влияющие на сегмент Monetary.

### 3. RFM-сегментация
Клиенты были оценены по шкале от 1 до 5 по трем метрикам:
* Recency (давность последней покупки).
* Frequency (количество заказов).
* Monetary (сумма трат).

## Результаты и сегменты
* Champions: Лояльные клиенты, покупающие часто и на стабильные суммы.
* Need Attention: Покупатели с высоким чеком, совершившие покупку давно (часто разовые покупки дорогих товаров).
* Hibernating: Массовый сегмент разовых покупок, совершенных более полугода назад.

## Бизнес-рекомендации
* Удержание новичков: Внедрение приветственных бонусов на второй заказ.
* Работа с VIP-выбросами: Персонализированный сервис для клиентов с высоким чеком.
* Фокус на масс-маркет: Акцент в рекламе на товары до 150 ед.

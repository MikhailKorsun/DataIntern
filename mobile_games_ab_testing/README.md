# Анализ A/B теста: Влияние игровых ворот на Retention в Cookie Cats 

## Описание проекта
В мобильной игре **Cookie Cats** игроки сталкиваются с "воротами" (gates), которые заставляют их ждать или совершать внутриигровую покупку для продолжения. Цель данного исследования — определить, как перенос первых ворот с **30-го** на **40-й уровень** влияет на удержание игроков (Retention).

## Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, Matplotlib, Seaborn, Statsmodels (для Z-теста).

## Основные этапы работы
1. **Загрузка и очистка данных:** Проверка структуры, поиск аномалий и анализ "нулевых" игроков (тех, кто не сыграл ни одного раунда).
2. **Анализ Retention 1 day:** Сравнение краткосрочного удержания между группами `gate_30` и `gate_40`.
3. **Анализ Retention 7 day:** Оценка долгосрочного влияния изменений на возвращаемость игроков.
4. **Статистическая проверка:** Использование Z-теста для долей (proportions z-test) для подтверждения значимости результатов.
5. **Визуализация:** Построение графиков с доверительными интервалами.

##  Результаты исследования

| Метрика | Относительное изменение | p-value | Значимость (alpha=0.05) |
| :--- | :--- | :--- | :--- |
| **Retention 1 day** | -1.32% | 0.0744 | Не значимо |
| **Retention 7 day** | **-4.31%** | **0.0016** | **Значимо** ✅ |

### Ключевые инсайты:
* **Краткосрочный эффект:** В первый день разница между группами не подтверждена статистически.
* **Долгосрочный эффект:** К 7-му дню наблюдается четкое и значимое падение удержания в тестовой группе. Игроки, столкнувшиеся с воротами позже, реже возвращаются в игру.

##  Финальная рекомендация
**Не переносить ворота на 40-й уровень.** Результаты теста показывают, что текущее расположение ворот на 30-м уровне лучше удерживает аудиторию в долгосрочной перспективе, что критически важно для монетизации и жизни игрового проекта.
